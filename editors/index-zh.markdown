# 编辑

在下方，您将看到负责本书内容的编辑---包括其特殊的数字功能---这一切之所以成为可能，是因为这本书是为互联网而创作，并且仅在此处存在。
{: .lead}

借助在线媒体，例如链接到贡献者的社交媒体账号、在书籍章节中直接嵌入视频和其他媒体、定期更新内容等，可能性是无穷无尽的。如果您有任何好点子，请[联系我们]({{ site.url }}{{ site.baseurl }}/contact-us/)！

# 名誉编辑 {#emeritus-editors}

我们站在巨人的肩膀上。
{: .lead}

这本在线书籍的构想最初由下方所示的三位编辑提出。尽管他们都学术成果丰硕，但他们也认识到，大多数作者的学术工作并未获得直接报酬。然而，却有整个行业，其唯一产品正是这些工作---章节、综述、研究、评论、同行评议等。互联网则提供了一个颠覆这一体系的机会，使小儿泌尿科医生能够以开放的方式发表他们的专业知识，供所有人免费阅读。Duncan Wilcox 医生曾表示，"[Pediatric Urology Book] 是我最引以为傲的学术成果。"

2020年，三位荣休编辑欣然提出交棒，希望让新的内容和理念蓬勃发展。
